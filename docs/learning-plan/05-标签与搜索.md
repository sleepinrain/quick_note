## 开发任务

### 1. 扩展数据库表

新增：

```sql
CREATE TABLE IF NOT EXISTS tags (
    id         TEXT PRIMARY KEY,
    name       TEXT NOT NULL UNIQUE,
    created_at TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS note_tags (
    note_id TEXT NOT NULL,
    tag_id  TEXT NOT NULL,
    PRIMARY KEY (note_id, tag_id),
    FOREIGN KEY (note_id) REFERENCES notes(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_note_tags_tag_id ON note_tags(tag_id);
```

### 2. 规范标签规则

第一版规则：

- 用户可以输入 `work, idea, todo`。
- 保存时去掉前后空格。
- 保存时全部转成小写。
- 保存时去掉开头的 `#`。
- 空标签不保存。
- 重复标签只保存一次。

示例：

```text
" Work, #Idea, work "
```

应保存为：

```text
["work", "idea"]
```

### 3. 实现标签保存

保存笔记时：

1. 保存 `notes`。
2. 找到或创建 `tags`。
3. 删除旧的 `note_tags`。
4. 插入新的 `note_tags`。

### 4. 实现搜索解析

建议创建：

```text
src/search/parseQuery.ts
```

第一版只支持：

```text
#work  -> 标签搜索
work   -> 普通关键词搜索
空字符串 -> 最近更新
```

### 5. 实现标签搜索

输入 `#work` 时：

- 查找 `tags.name = 'work'`。
- 通过 `note_tags` 找到笔记。
- 按 `notes.updated_at DESC` 排序。

### 6. 实现普通关键词搜索

第一版可以先用 `LIKE`：

```sql
WHERE title LIKE ? OR content LIKE ?
```

后续数据量大或英文搜索需求强，再升级 SQLite FTS5。

## 验收标准

- 可以给笔记添加多个标签。
- 重启应用后标签仍然存在。
- 输入 `#work` 只显示带 `work` 标签的笔记。
- 输入普通关键词可以搜索标题和正文。
- 空搜索显示最近更新的笔记。
- 标签重复、大小写、`#` 前缀都能正确处理。
