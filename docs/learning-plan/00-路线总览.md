# Quick Note 学习与开发路线总览

本文档是整个学习和开发计划的入口。目标是用 `quick_note` 项目同时学习：

- Rust 基础和 Tauri 桌面开发
- TypeScript、React、前端工程
- Git / GitHub 的实际工作流
- 一个完整桌面应用从初始化到打包发布的过程

## 核心原则

1. 每个阶段都必须产生一个可验证结果。
2. 每个阶段至少有一次 Git commit。
3. 不提前追求复杂架构，先保证功能闭环。
4. 不在 MVP 阶段加入云同步、AI、复杂动画、富文本编辑器。
5. 每次新对话开始时，先让 Codex 阅读本文件、当前阶段文件和 `99-进度记录.md`。

## 协作方式

本项目采用分步执行方式：

1. Codex 负责根据当前阶段给出具体任务、命令、代码和检查方式。
2. 用户负责在本机执行命令、阅读代码、反馈运行结果和报错信息。
3. 如果上下文丢失，Codex 必须先恢复进度，不要重新规划整条路线。
4. 每一步优先完成一个可验证的小结果，再进入下一步。
5. 学习深度由用户自行把握，Codex 的输出重点是准确、可执行、工程质量可靠。

## 推荐技术路线

- 桌面框架：Tauri 2
- 前端框架：React + TypeScript + Vite
- 样式：Tailwind CSS
- 数据库：SQLite
- 搜索：标签精确搜索 + 普通关键词搜索，后续再升级 FTS5
- 代码托管：GitHub
- 开发平台：Windows 优先

## 总体验收标准

当下面条件全部满足时，第一版项目完成：

- GitHub 上有完整项目仓库。
- 可以本地启动 Tauri 桌面应用。
- 可以创建、编辑、删除笔记。
- 笔记数据保存到本地 SQLite，重启后仍存在。
- 可以给笔记添加标签。
- 可以通过 `#tag` 搜索标签。
- 可以通过普通关键词搜索标题和正文。
- 可以通过悬浮搜索栏快速搜索。
- 可以点击结果打开预览窗口。
- 可以通过托盘重新打开主窗口。
- 可以通过全局快捷键唤起搜索栏。
- 有基础自动化测试。
- 可以打包 Windows 安装包或可执行文件。
