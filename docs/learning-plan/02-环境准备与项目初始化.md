# 阶段 2：环境准备与项目初始化

## 阶段目标

创建一个可以运行的 Tauri + React + TypeScript 桌面应用。这个阶段只要求跑通空应用，不实现笔记功能。

## 前置条件

- 阶段 1 已完成。
- GitHub 仓库可用。
- 本地能执行 Git 基础命令。

## 学习重点

- Node.js 和 npm
- Rust toolchain
- Tauri 项目结构
- Vite 开发服务器
- 前端代码和 Tauri 后端代码的分工

## 开发任务

### 1. 安装基础工具

需要安装：

- Node.js LTS
- Rust
- Visual Studio Build Tools
- WebView2 Runtime

安装后检查版本：

```bash
node -v
npm -v
rustc --version
cargo --version
```

### 2. 创建 Tauri 项目

在合适的位置使用 Tauri 官方脚手架创建项目。

推荐选择：

- Package manager: npm
- UI template: React
- Language: TypeScript

常用命令：

```bash
npm create tauri-app@latest
```

如果脚手架要求输入项目名，使用：

```text
quick_note
```

如果当前目录已经是项目根目录，要注意不要把新项目嵌套到错误目录里。必要时先和 Codex 确认目录结构。

### 3. 安装依赖

进入项目目录后执行：

```bash
npm install
```

### 4. 启动开发模式

```bash
npm run tauri dev
```

预期结果：

- Vite 开发服务器启动。
- Tauri 桌面窗口打开。
- 修改前端页面后可以看到变化。

### 5. 理解项目结构

重点认识：

```text
src/                 # React 前端代码
src-tauri/           # Rust / Tauri 桌面侧代码
src-tauri/tauri.conf.json 或 tauri.conf.json
package.json
vite.config.ts
```

## 常见问题

### npm 命令找不到

通常是 Node.js 没有安装成功，或者终端没有重启。

### cargo 命令找不到

通常是 Rust 没有安装成功，或者环境变量没有刷新。

### Tauri 编译失败

优先检查 Visual Studio Build Tools 和 WebView2 是否安装完整。
