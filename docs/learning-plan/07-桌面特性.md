# 阶段 7：桌面特性

## 阶段目标

把普通笔记应用变成真正的桌面 Quick Note 工具：悬浮搜索栏、预览窗口、托盘、全局快捷键。

## 前置条件

- 阶段 6 已完成。
- 主窗口、标签、搜索都已经可用。

## 学习重点

- Tauri 多窗口
- 窗口配置
- 窗口事件
- 系统托盘
- 全局快捷键
- 桌面应用生命周期

## 开发任务

### 1. 增加悬浮搜索栏窗口

建议窗口名：

```text
quick-search
```

窗口行为：

- 小尺寸。
- 可以置顶。
- 无边框。
- 初期可以不透明。
- 不在任务栏显示。
- 获得焦点后可以输入搜索。

第一版不要急着做透明和毛玻璃。先保证窗口稳定。

### 2. 增加搜索结果浮层

搜索栏输入后显示结果：

- 标题
- 标签
- 更新时间
- 内容摘要

点击结果后打开预览窗口。

### 3. 增加预览窗口

建议窗口名：

```text
note-preview
```

第一版只维护一个预览窗口：

- 点击不同结果时复用同一个窗口。
- 窗口内容根据当前笔记切换。
- 支持跳转到主窗口编辑。

不要一开始为每条笔记创建独立窗口。

### 4. 增加系统托盘

托盘菜单建议：

- 打开主窗口
- 打开搜索栏
- 新建笔记
- 退出

关闭主窗口时，第一版建议隐藏到托盘，不直接退出应用。

### 5. 增加全局快捷键

建议默认快捷键：

```text
Ctrl + Alt + Space
```

行为：

- 搜索栏隐藏时，显示并聚焦。
- 搜索栏已显示时，聚焦输入框。
- 快捷键注册失败时，显示错误或降级为托盘打开。

### 6. 增加基础设置

建议设置：

- 快捷键
- 主题
- 关闭行为
- 搜索栏位置

本阶段可以只做最必要设置，不要扩展太多。

## Git 提交要求

建议拆分提交：

```text
feat: add quick search window
feat: add note preview window
feat: add system tray
feat: add global shortcut
```

## 验收标准

- 主窗口仍然可用。
- 悬浮搜索栏可以打开并搜索。
- 点击搜索结果能打开预览窗口。
- 关闭主窗口后应用仍在托盘。
- 托盘可以重新打开主窗口。
- 全局快捷键可以唤起搜索栏。
- 快捷键冲突时应用不会崩溃。

## 常见问题

### 搜索栏抢焦点

先保证手动打开和输入正常，再处理自动聚焦细节。

### 透明窗口显示异常

先关闭透明效果。透明、阴影、点击穿透属于后续优化。

### 多窗口状态不同步

优先使用事件通知或重新读取数据库，不要在多个窗口中维护互相冲突的复杂状态。
